## ⚡ Tech Stack & Architecture

- **Frontend**: React 18 + Vite
- **Styling**: Vanilla CSS + Tailwind CSS with Glassmorphism & Cyber Neon Glow
- **Canvas Animations**: Multi-layered interactive constellation, magnetic cursor physics, stardust embers, and expanding click shockwaves
- **Fonts**: Montserrat, Poppins & Outfit (Google Fonts)
